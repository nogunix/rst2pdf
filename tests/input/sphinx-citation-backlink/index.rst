Citations
=========

A citation reference is the source of a link to the citation, and the
citation is given a link back to it.  That makes the reference the
destination of a link as well as the source of one, and the identifier it
is reached by is minted by the transformation rather than written here --
which is why a failure names something like "id1" that appears nowhere in
this file.

The behaviour is described in the datasheets [DS1]_ and [DS2]_.
